Asked: Asked Claude Code (Claude Opus 5.5) to complete SCRUM-31: unit tests for the API layer and coverage reporting in CI.

Produced: Five new test classes: `JsonTest`, `ProfileBindingTest`, `EditProfileTest`, `MentoringAppTest` (every route over real HTTP in stub mode) and `SharedCoreClientTest` (live mode against a fake Shared Core). To make the routes testable, server setup moved out of `main` into `MentoringApp.start(...)`. JaCoCo was added to `build.gradle` with a coverage floor of 85% lines and 75% branches, and CI now posts a coverage table (`scripts/coverage-summary.sh`) and uploads the HTML report. Coverage went from 39.9% to 93.6% of lines, with 119 tests in all. The tests found three bugs, now fixed. A refused profile `PUT` still changed the stored profile. Deeply nested JSON overflowed the stack and got no response instead of a 400. An empty `Bearer ` header was sent to Shared Core as a token and returned 502 instead of 401.

Changed: We kept the coverage floor below the measured numbers so small changes don't fail CI. We left the directory's maximum page size at 100 instead of the SOW's 50, because changing it after the feature freeze needs the team's agreement.
